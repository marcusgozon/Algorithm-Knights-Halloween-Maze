# 🎃 Algorithm Knights Halloween Maze

A spooky pixel‑art maze game made for the **Algorithm Knights (Data Structures and Algorithms org)** Halloween event.  
Players collect candy, dodge ghosts, and escape through the crypt door—then learn how the maze connects to **Data Structures and Algorithms (DSA)** with animations, everyday examples, and a short quiz.

---

## ✨ Features
- Playable on **phones and laptops** (no install, no account).
- Three levels: **Cozy, Spooky, Nightmare**.
- Ghost AI powered by **Breadth‑First Search (BFS)**.
- Maze generation using **Depth‑First Search (DFS)** + stack.
- Result card with stats, score, and fun titles.
- Beginner‑friendly DSA lesson + quiz after each run.
- Easy to customize: colors, maze size, quiz questions, music.
- **Leaderboard system** → Top 5 scores are displayed after each run.
- **Login & verification** → Players can log in with Gmail; a 6‑digit code is sent to confirm valid email before saving scores.

---

## 🎮 How to Play
1. Open the game in your browser.
2. Log in with Gmail (verify with 6‑digit code).
3. Enter your name, choose a level, and (optional) type a seed.
4. Collect all the candy hidden in dead ends.
5. Escape through the glowing crypt door.
6. View your results, explore the DSA lesson, and check if you made it to the **Top 5 leaderboard**.

**Controls:**
- Laptop/Desktop → Arrow keys or `W A S D`
- Phone/Tablet → On‑screen buttons or swipe

---

## 🧩 DSA Concepts Behind the Game
- **Graph** → Maze tiles and corridors  
- **DFS + Stack** → Maze generation  
- **BFS + Queue** → Ghost pathfinding  
- **Tree** → Maze structure (no loops, one path between nodes)  
- **Backtracking** → Retracing steps at dead ends  

---

## 🎯 Purpose
This project was created for the Algorithm Knights Sub-Org Halloween Event to help students visualize how algorithms work in solving maze problems. It blends education and entertainment, making DSA concepts easier to understand.
