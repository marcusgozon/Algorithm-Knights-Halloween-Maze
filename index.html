The big idea in 30 seconds

Data structure = a way to keep things organized so they are easy to use. Think of a pile of plates, a line of people, or a map.

Algorithm = a recipe. Step-by-step instructions to solve a problem, like "how to find the way out of a maze".

The map (Graph)

Picture this: a map of your school. Each room is a dot. Each hallway between two rooms is a line. A map made of dots and lines is called a graph.

Your maze is the same thing:

  • Every open tile is a dot. The proper name is vertex.
  • Every step from one tile to the next is a line. The proper name is edge.
  • A wall just means "there is no line here".

Press Replay above and watch the dots light up.

A computer remembers a graph by keeping a "who is next to me?" list for every dot, like a list of neighbors. Here are the first few tiles of your maze:


      

      
Why does this matter? Lots of things are graphs: a subway map, friends on social media, and the roads in a GPS app. Once you see something as dots and lines, you can reuse the same tricks on it.

      

        For the curious: how fast is it?
        
Computer scientists write the work as O(V + E). V is the number of dots and E is the number of lines. It means the computer looks at each dot and each line about one time. A maze twice as big takes about twice as long. That is fast!

      

    


    

      
Building the maze (DFS + Stack)

      
Picture this: you explore a cave with a ball of string. You walk into a tunnel, then another, then another, as far as you can. At a dead end, you follow the string back to the last place that had another tunnel, and you try that one. Going deep first like this is called DFS (Depth-First Search). It is an algorithm, which just means a recipe of steps.

      
But how does the computer remember where to go back to? It uses a stack. A stack is a pile of plates:

      
    
        
  • Walk into a new room = put a plate on top of the pile.
    • 
        
  • Stuck at a dead end = take the top plate off and step back.
    • 
        
  • The last plate you put on is the first one you take off. We say "last in, first out".
    • 
      

      
Press Replay above. Bright red tiles are the plates in the pile. The yellow tile is the top plate.

      
The recipe in plain words:

      
    
        
  1. Stand in a room and mark it as visited.
    2. 
        
  2. Look next door for a room you have never visited.
    3. 
        
  3. Found one? Dig a tunnel to it, step in, and put a plate on the pile.
    4. 
        
  4. No new rooms? Take the top plate off and step back.
    5. 
        
  5. Keep going until the pile is empty. Now every room is connected!
    6. 
      

      
You use a stack every day: the Undo button and the Back button in your browser. The last thing you did is the first thing that gets undone.

      

        Peek at the real code (optional)

const stack = [start];                 // our pile of plates
while (stack.length) {
  const room = stack[stack.length - 1];   // look at the top plate
  const next = pickRandom(newNeighbors(room));
  if (next) {
    openDoorBetween(room, next);        // dig a tunnel
    stack.push(next);                   // new plate on top: go deeper
  } else {
    stack.pop();                        // stuck! take a plate off: go back
  }
}

      

    


    

      
The ghost (BFS + Queue)

      
Picture this: you drop a pebble in a pond. The ripple spreads in circles: first everything 1 step away, then 2 steps away, then 3. The ghost searches the same way. This is called BFS (Breadth-First Search). It is another algorithm.

      
To remember what to check next, BFS uses a queue. A queue is the line at the canteen:

      
    
        
  • A new tile to check = join the back of the line.
    • 
        
  • The tile at the front of the line gets checked first.
    • 
        
  • The first one to join is the first one served. We say "first in, first out".
    • 
      

      
Press Replay above. White tiles are the people waiting in line. The colors show how far each tile is from the start.

      
The recipe in plain words:

      
    
        
  1. Start at the ghost's tile and join the line.
    2. 
        
  2. Serve the tile at the front of the line.
    3. 
        
  3. Put its new neighbors at the back of the line.
    4. 
        
  4. Repeat. Close tiles are served first because they joined the line first.
    5. 
        
  5. When you reach the player, trace back the way you came. That is the shortest route!
    6. 
      

      
Why is it the shortest way? Because near tiles are always checked before far tiles. The first time the ripple touches you, it took the fewest steps possible.

      
You see this in real life: "People you may know" on social media. It checks your friends first, then friends of friends, and so on.

      

        For the curious: what if some tiles were muddy?
        
Then not every step costs the same, and a plain line is not enough. We would use a VIP line where the cheapest choice goes first. That is called a priority queue, and the algorithm is named Dijkstra. GPS apps use it. A fun thing to learn next!

      

      

        Peek at the real code (optional)

const queue = [start];                // the line (first in, first out)
const cameFrom = new Map();         // who sent us here?
while (queue.length) {
  const current = queue.shift();      // serve the person at the front
  if (current === goal) break;      // found it!
  for (const n of neighbors(current)) {
    if (!seen.has(n)) {
      seen.add(n);
      cameFrom.set(n, current);        // remember the way back
      queue.push(n);                   // join the back of the line
    }
  }
}

      

    


    

      
One route only (Tree)

      

      
Picture this: a real tree, or a family tree. A branch splits into smaller branches, and the tips are called leaves. Branches never grow back together.

      
Your maze has no loops, so it works like a tree:

      
    
        
  • There is exactly one route between any two tiles. That is why you never found a second way to the door.
    • 
        
  • The dead ends are the leaves. That is why the candy was hiding there!
    • 
        
  • Number of lines = number of dots minus 1. A family tree works the same way: everyone except the oldest has exactly one line going up to a parent.
    • 
      

      
The teal tiles show the best possible walk. You walk down each branch that has candy and come back. You walk the road to the door only once.

      
What if we broke a wall and made a loop? Then there would be two ways to get somewhere, and the computer would need BFS to pick the shorter one.
